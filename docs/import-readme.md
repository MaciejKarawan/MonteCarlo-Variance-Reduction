# Monte Carlo Variance Reduction

Academic project by Adamek and Karawan on variance reduction in Monte Carlo option pricing. Original attribution is retained in the accompanying report.

`code/` contains crude Monte Carlo, antithetic variables, control variates, stratification and comparison/plotting scripts. The PDF report contains the original write-up.

Dependencies: NumPy, SciPy and matplotlib. Scripts use sibling imports: run from `code/` or configure the Python module path accordingly. Inspect simulation budgets before running.

Python syntax was checked during import. Simulations and reported numerical results were not rerun. No licence was assigned to the collaborative work.
